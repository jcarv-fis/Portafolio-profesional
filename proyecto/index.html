// Sobre mí

Desarrollador backend orientado a la arquitectura de software

Soy desarrollador de software especializado en backend. Diseño la lógica de negocio, la estructura de datos y la arquitectura que hay detrás de cada aplicación: lo que el usuario no ve, pero es lo que sostiene todo.

Trabajo principalmente con Java y Spring Boot, además de .NET, diseñando y consumiendo APIs REST sobre bases de datos relacionales, con arquitectura por capas y código limpio. Me caracterizo por la responsabilidad, la organización y el aprendizaje constante, y disfruto construir en equipo soluciones que resuelvan problemas reales.
